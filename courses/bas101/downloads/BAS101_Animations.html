BAS101 — Engineering Physics: Animated Concept Companion

An interactive, animated companion to the BAS101 lecture notes. Each card below is a self-contained, looping animation illustrating one key concept from the corresponding unit — built to accompany (not replace) the full written notes, since Word documents cannot play animations.

▶ Animations auto-play when scrolled into view and pause when off-screen to save battery. Use Pause / Replay on any card to control it individually.
