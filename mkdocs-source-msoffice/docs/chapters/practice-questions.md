# Appendix C: Sample Question Bank for Revision {: #appendix-c }

**परिशिष्ट स: पुनरावृत्ति हेतु प्रश्न-बैंक**

The following sample questions mirror the style typically expected in internal assessments and viva-voce for a practical/vocational course. Students should attempt these after completing all chapter exercises.

## C.1 Multiple Choice Questions (MCQs) {: #sec-c-1 }

1.  The default file extension of a Word document (2007 onwards) is: (a) .doc (b) .docx (c) .txt (d) .rtf — Answer: (b)

2.  Which shortcut key is used to apply Justify alignment in Word? (a) Ctrl+L (b) Ctrl+E (c) Ctrl+J (d) Ctrl+R — Answer: (c)

3.  In Excel, which symbol must every formula begin with? (a) \# (b) @ (c) = (d) \$ — Answer: (c)

4.  Which Excel reference type does NOT change when a formula is copied to another cell? (a) Relative (b) Absolute (c) Both change (d) Neither — Answer: (b)

5.  Which function in Excel would you use to count cells meeting a condition? (a) SUM (b) COUNTIF (c) AVERAGE (d) VLOOKUP — Answer: (b)

6.  In PowerPoint, an effect applied BETWEEN two slides is called a: (a) Animation (b) Transition (c) Template (d) Placeholder — Answer: (b)

7.  Which key starts a PowerPoint slide show from the very first slide? (a) F2 (b) F5 (c) F7 (d) F12 — Answer: (b)

8.  Mail Merge in Word is primarily used for: (a) Formatting fonts (b) Creating personalised bulk letters (c) Inserting pictures (d) Checking spelling — Answer: (b)

9.  Which view in PowerPoint shows small thumbnails of all slides for easy reordering? (a) Normal (b) Slide Sorter (c) Reading View (d) Notes Page — Answer: (b)

10. A Pivot Table in Excel is primarily used to: (a) Draw shapes (b) Summarise and analyse large datasets interactively (c) Check spelling (d) Insert headers — Answer: (b)

11. The full form of WWW is: (a) World Wide Web (b) Wide World Web (c) World Web Wide (d) Web World Wide — Answer: (a)

12. Which of these is a valid email attachment size concern? (a) Attachments are always unlimited (b) Most providers limit attachments to about 25 MB (c) Attachments cannot contain images (d) Attachments must be sent via CC — Answer: (b)

13. A padlock icon in the browser address bar indicates: (a) The page is slow (b) The connection is secure (HTTPS) (c) The page has a virus (d) The page is bookmarked — Answer: (b)

14. Which key combination opens a new tab in most browsers? (a) Ctrl+N (b) Ctrl+T (c) Ctrl+B (d) Ctrl+H — Answer: (b)

15. In MS Access, which object is used to store raw data? (a) Form (b) Report (c) Table (d) Query — Answer: (c)

16. A field that uniquely identifies each record in an Access table is called a: (a) Foreign Key (b) Primary Key (c) Index Key (d) Query Key — Answer: (b)

17. Which MS Access object is best suited for user-friendly data entry? (a) Table (b) Query (c) Form (d) Report — Answer: (c)

18. Which shortcut key combination opens the Find and Replace dialog box in Word? (a) Ctrl+F (b) Ctrl+H (c) Ctrl+R (d) Both (a) and (b) can open related dialogs — Answer: (d)

19. A footnote in Word appears: (a) At the end of the document (b) At the bottom of the same page (c) At the top of the next page (d) In a separate file — Answer: (b)

20. Which feature automatically generates a list of headings with page numbers? (a) Mail Merge (b) Table of Contents (c) Watermark (d) Track Changes — Answer: (b)

21. In Excel, the function used to look up a value in the first column of a range is: (a) HLOOKUP (b) VLOOKUP (c) INDEX (d) SORT — Answer: (b)

22. Which Excel feature allows automatic colour-coding of cells based on their value? (a) Data Validation (b) Conditional Formatting (c) Freeze Panes (d) Pivot Chart — Answer: (b)

23. The intersection of a row and column in Excel is called a: (a) Field (b) Record (c) Cell (d) Range — Answer: (c)

24. Which shortcut inserts the current date in Excel? (a) Ctrl+; (b) Ctrl+Shift+; (c) Ctrl+D (d) Ctrl+T — Answer: (a)

25. In PowerPoint, which pane lists all the animations applied to objects on a slide, in order? (a) Slide Sorter (b) Animation Pane (c) Notes Pane (d) Outline Pane — Answer: (b)

26. SmartArt in PowerPoint is primarily used to: (a) Insert audio (b) Represent information/ideas visually as diagrams (c) Check spelling (d) Password-protect a file — Answer: (b)

27. Which PowerPoint view is best for adding detailed spoken-delivery notes for the presenter? (a) Slide Sorter (b) Reading View (c) Notes Page (d) Outline View — Answer: (c)

28. A Domain Name is translated into an IP Address by a: (a) Web Browser (b) Search Engine (c) DNS Server (d) ISP — Answer: (c)

29. Which of these is an example of a Web Browser? (a) Gmail (b) Google Chrome (c) MS Access (d) WhatsApp — Answer: (b)

30. Which email field sends a copy WITHOUT the recipient's address being visible to others? (a) To (b) (c) BCC (d) Subject — Answer: (c)

31. Fraudulent emails/websites designed to steal passwords are known as: (a) Spam (b) Phishing (c) Bookmarking (d) Filtering — Answer: (b)

32. Which of these is the safest sign that a website is using an encrypted connection? (a) A colourful homepage (b) A padlock icon and 'https://' (c) A pop-up advertisement (d) A long domain name — Answer: (b)

33. In MS Access, a field whose value refers to the Primary Key of another table is called a: (a) Composite Key (b) Foreign Key (c) Index (d) AutoNumber — Answer: (b)

34. Which MS Access data type is best suited for storing monetary values? (a) Number (b) Currency (c) Short Text (d) Yes/No — Answer: (b)

35. Which MS Access object would you use to print a neatly formatted, grouped summary of data? (a) Table (b) Query (c) Form (d) Report — Answer: (d)

36. A relationship where one Student record can relate to many Fee Payment records is called: (a) One-to-One (b) One-to-Many (c) Many-to-Many (d) No relation — Answer: (b)

37. Which key toggles between Edit mode and Navigation mode within an MS Access datasheet cell? (a) F1 (b) F2 (c) F5 (d) F7 — Answer: (b)

38. Which of the following is NOT a basic service commonly provided over the Internet? (a) Email (b) File Transfer (c) Formula Auditing (d) Video Calling — Answer: (c)

39. Which browser feature lets a user quickly revisit a saved page without retyping its URL? (a) History (b) Bookmarks/Favourites (c) Downloads (d) Incognito Mode — Answer: (b)

40. Which of these connection types is generally the fastest for home use today? (a) Dial-Up (b) Fibre-Optic (FTTH) (c) Satellite (d) 2G Mobile Data — Answer: (b)

41. The 'S' in HTTPS specifically indicates that the connection is: (a) Slow (b) Secure/Encrypted (c) Shared (d) Static — Answer: (b)

42. Which Word feature would you use to send the same letter to 50 different recipients with personalised names and addresses? (a) Track Changes (b) Mail Merge (c) Comments (d) AutoCorrect — Answer: (b)

43. Which Excel chart type is best suited for showing trends over time? (a) Pie Chart (b) Line Chart (c) Scatter Chart (d) Doughnut Chart — Answer: (b)

44. Which shortcut duplicates the currently selected slide in PowerPoint? (a) Ctrl+D (b) Ctrl+M (c) Ctrl+N (d) Ctrl+P — Answer: (a)

45. An IP Address is best described as: (a) A person's email password (b) A unique numeric address identifying a device on a network (c) A type of virus (d) A file extension — Answer: (b)

46. Which of these best describes 'Bandwidth'? (a) The width of a web page (b) The maximum data that can travel through a connection per second (c) A type of email attachment (d) A database field type — Answer: (b)

47. Which MS Access view allows full control over a table's field names and data types? (a) Datasheet View (b) Design View (c) Layout View (d) Print Preview — Answer: (b)

48. Which of these would you tick when creating a table relationship to prevent orphaned records? (a) Cascade Delete (b) Enforce Referential Integrity (c) AutoNumber (d) Compact and Repair — Answer: (b)

49. Which of the following is a strong password practice? (a) Reusing the same password everywhere (b) Using your name and date of birth (c) A unique mix of letters, numbers, and symbols for each account (d) Sharing your password with close friends — Answer: (c)

50. In Excel, which reference type is written with dollar signs, e.g., \$A\$1? (a) Relative (b) Absolute (c) Mixed only (d) Circular — Answer: (b)

51. Which key combination applies Bold formatting in Word/Excel/PowerPoint? (a) Ctrl+B (b) Ctrl+I (c) Ctrl+U (d) Ctrl+N — Answer: (a)

52. In an Access table, each column is referred to as a: (a) Record (b) Field (c) Row (d) Report — Answer: (b)

53. Which is the correct term for one complete row of data in a database table? (a) Field (b) Record (c) Query (d) Form — Answer: (b)

54. Which of the following file extensions belongs to an MS Access database? (a) .xlsx (b) .pptx (c) .accdb (d) .docx — Answer: (c)

55. Compact and Repair Database in MS Access is primarily used to: (a) Change the Primary Key (b) Reduce file size and fix minor corruption (c) Create a new report (d) Send an email — Answer: (b)

## C.3 Practical / Long-Answer Questions {: #sec-c-3 }

1.  Create a formatted one-page resume (bio-data) in MS Word using Styles, a Table for personal details, and appropriate headers/footers.

2.  Create an Excel workbook to record and analyse the attendance of 20 students over one month, using COUNTIF to calculate attendance percentage and Conditional Formatting to flag students below 75% attendance.

3.  Design an 8-10 slide PowerPoint presentation on any topic of your subject specialisation, incorporating SmartArt, at least one chart, hyperlinked navigation, and appropriately-applied transitions/animations.

4.  Explain, with suitable illustrations/diagrams, how MS Word, Excel and PowerPoint can be used together to prepare a complete project report and its accompanying viva presentation.

5.  Create a Gmail (or similar) email account, then send an email with at least one file attachment to your teacher, with a suitable Subject line.

6.  Create an MS Access database for a small library, with a Books table and a Members table linked by a One-to-Many relationship, including one query and one report.

7.  Perform a Mail Merge in MS Word to generate 10 personalised invitation letters using an Excel sheet of names and addresses as the data source; submit the merged output as a single document.

8.  Create an Excel workbook analysing the monthly expenses of a household across at least 6 categories, including a Pivot Table summary and a suitable chart (e.g., Pie or Bar) illustrating the spending distribution.

9.  Design a 6-slide PowerPoint presentation introducing your college/institution, using a consistent Slide Master theme, at least one embedded chart, and rehearsed slide timings suitable for an unattended kiosk display.

10. Compose and send an email to two recipients (using To and CC appropriately) with a Word document and an Excel sheet both attached, and BCC yourself for a record.

11. Design an MS Access database to manage a small shop's inventory, with a Products table and a Suppliers table linked appropriately, including at least two queries (one with a numeric criterion, one with a text criterion) and one grouped report.

12. Research and safely browse three government e-governance websites relevant to students (e.g., scholarship portals, examination boards), noting their URLs and one key service each offers, while verifying each uses HTTPS.

13. Create a Word document with a multi-level numbered list (e.g., a lab manual's steps and sub-steps), a correctly captioned figure, and an auto-updating Table of Contents.

14. Build an Excel gradebook for a class of 15 students across 4 subjects, calculating totals, percentages, and grades using nested IF or LOOKUP functions, with the top 3 students highlighted using Conditional Formatting.

15. Create a PowerPoint presentation explaining a step-by-step process of your choice (e.g., a science experiment or a cooking recipe) using SmartArt process diagrams and appropriate animations to reveal each step in sequence.

16. Set up email filters/rules in your email account to automatically label incoming messages from your class group, and demonstrate the result with at least three test emails.

17. Design a two-table MS Access database of your own choice (e.g., Hostel Rooms and Residents, or Sports Equipment and Issue Records) including a relationship, one form for data entry, and one report with a calculated total in the footer.

18. Prepare a short comparative note (using a Word table) contrasting MS Word, MS Excel, MS PowerPoint, Email, and MS Access in terms of purpose, basic unit, and typical output — supporting the summary with one real example from each.

19. Export a Report created in MS Access to both PDF and Excel formats, and explain in 3-4 sentences the situations in which each exported format would be more useful.

20. Simulate a safe-use-of-Internet audit of your own browser and one email/social-media account: check and note whether HTTPS is used by default, whether Two-Factor Authentication is enabled, and review the current privacy settings, listing any two improvements you would make.
