# Appendix A: Glossary of Key Terms {: #appendix-a }

**परिशिष्ट अ: प्रमुख शब्दावली**

This glossary lists important technical terms used throughout these notes, with a short bilingual explanation, for quick revision.

| **Term**                 | **Meaning (English)**                                                                        | **अर्थ (हिन्दी)**                                                 |
|--------------------------|----------------------------------------------------------------------------------------------|-----------------------------------------------------------------|
| Cursor / Insertion Point | The blinking vertical line showing where typed text will appear.                             | टिमटिमाती खड़ी रेखा जो दर्शाती है कि टाइप किया गया पाठ कहाँ दिखेगा।   |
| Ribbon                   | The panel of tabs and command-groups at the top of an Office window.                         | ऑफिस विंडो के ऊपरी भाग में टैब व कमांड-समूहों का पैनल।                   |
| Template                 | A ready-made file structure/design used as a starting point for a new document.              | नए दस्तावेज़ हेतु प्रयुक्त पूर्व-निर्मित संरचना/डिज़ाइन।                     |
| Clipboard                | Temporary memory holding the last Cut/Copied item, ready to Paste.                           | अस्थायी मेमोरी जिसमें अंतिम कट/कॉपी की गई वस्तु रहती है।                |
| Font                     | The design/typeface of characters, e.g., Calibri, Arial.                                     | अक्षरों की बनावट/शैली, जैसे कैलिबरी, एरियल।                           |
| Style                    | A named, reusable set of formatting instructions.                                            | फॉर्मेटिंग निर्देशों का नामित, पुन: प्रयोज्य समूह।                        |
| Cell                     | The intersection of a row and a column in a spreadsheet.                                     | स्प्रेडशीट में पंक्ति व स्तंभ का प्रतिच्छेदन बिंदु।                           |
| Cell Reference/Address   | The unique label of a cell, e.g., B5.                                                        | किसी सेल का अद्वितीय नाम, जैसे B5।                                  |
| Formula                  | A user-written calculation beginning with '='.                                               | '=' चिन्ह से शुरू होने वाली उपयोगकर्ता-निर्मित गणना।                   |
| Function                 | A ready-made formula provided by Excel, e.g., SUM, IF.                                       | एक्सेल द्वारा प्रदत्त पूर्व-निर्मित गणना, जैसे SUM, IF।                   |
| Workbook                 | An Excel file, which may contain many worksheets.                                            | एक एक्सेल फ़ाइल, जिसमें कई वर्कशीट हो सकती हैं।                         |
| Slide                    | One page/screen of a PowerPoint presentation.                                                | पावरपॉइंट प्रस्तुति का एक पृष्ठ/स्क्रीन।                                |
| Placeholder              | A dashed box on a slide reserved for title/content.                                          | स्लाइड पर शीर्षक/सामग्री हेतु आरक्षित धराशायी बॉक्स।                   |
| Transition               | The visual effect between two consecutive slides.                                            | दो लगातार स्लाइडों के बीच का दृश्य प्रभाव।                            |
| Animation                | A visual effect applied to an object within one slide.                                       | एक ही स्लाइड के भीतर किसी वस्तु पर लागू दृश्य प्रभाव।                   |
| Mail Merge               | Combining one main document with a data list to create many personalised copies.             | एक मुख्य दस्तावेज़ को डेटा सूची से जोड़कर अनेक व्यक्तिगत प्रतियाँ बनाना।      |
| Pivot Table              | An interactive tool to summarise large datasets by dragging fields.                          | फ़ील्ड को खींचकर बड़े डेटा सेट को संक्षेप में प्रस्तुत करने वाला इंटरैक्टिव उपकरण। |
| SmartArt                 | A ready-made diagram into which text is typed directly.                                      | पूर्व-निर्मित आरेख जिसमें सीधे पाठ टाइप किया जाता है।                   |
| Header/Footer            | Repeating content areas at the top/bottom of every page or slide.                            | प्रत्येक पृष्ठ/स्लाइड के ऊपर/नीचे दोहराई जाने वाली सामग्री का क्षेत्र।       |
| AutoCorrect              | A feature that automatically fixes common typing errors.                                     | सामान्य टंकण त्रुटियों को स्वतः ठीक करने वाली सुविधा।                   |
| Internet                 | A global network of interconnected computer networks using common protocols (TCP/IP).        | परस्पर जुड़े कंप्यूटर नेटवर्कों का वैश्विक जाल।                             |
| World Wide Web (WWW)     | A collection of linked documents (web pages) accessed via browsers, running on the Internet. | इंटरनेट पर चलने वाली, हाइपरलिंक से जुड़े वेब पृष्ठों की सेवा।                |
| URL                      | The complete web address of a page, e.g., https://www.example.com.                           | किसी वेब पृष्ठ का पूर्ण पता।                                         |
| Web Browser              | Software used to access and display web pages, e.g., Chrome, Edge.                           | वेब पृष्ठ देखने हेतु प्रयुक्त सॉफ्टवेयर।                                    |
| ISP                      | A company providing a paid connection to the Internet.                                       | इंटरनेट कनेक्शन प्रदान करने वाली कंपनी।                                |
| HTTPS                    | A secure, encrypted version of the HTTP protocol, shown by a padlock icon.                   | HTTP का सुरक्षित, एन्क्रिप्टेड संस्करण।                                 |
| Phishing                 | A fraudulent attempt, often via email, to steal passwords or card details.                   | पासवर्ड अथवा कार्ड विवरण चुराने का धोखाधड़ी भरा प्रयास।               |
| Attachment               | A file sent along with an email rather than typed into its body.                             | ईमेल के साथ भेजी गई फ़ाइल।                                          |
| CC / BCC                 | Carbon Copy / Blind Carbon Copy — ways of sending an email copy to additional recipients.    | अतिरिक्त प्राप्तकर्ताओं को ईमेल की प्रति भेजने के तरीके।                   |
| Database                 | An organised collection of related data.                                                     | संबंधित डेटा का संगठित संग्रह।                                        |
| DBMS                     | Database Management System — software used to create and manage databases.                   | डेटाबेस बनाने व प्रबंधित करने का सॉफ्टवेयर।                             |
| Table (Access)           | The object that stores raw data in rows (records) and columns (fields).                      | पंक्तियों व स्तंभों में कच्चा डेटा संग्रहीत करने वाली वस्तु।                   |
| Primary Key              | A field whose value uniquely identifies each record in a table.                              | प्रत्येक रिकॉर्ड को विशिष्ट रूप से पहचानने वाला फ़ील्ड।                   |
| Foreign Key              | A field that links to the Primary Key of another, related table.                             | किसी अन्य तालिका की प्राइमरी की से जुड़ने वाला फ़ील्ड।                  |
| Query                    | A request that returns only the records matching specified criteria.                         | निर्दिष्ट शर्तों को पूरा करने वाले रिकॉर्ड लौटाने वाला अनुरोध।            |
| Form (Access)            | A user-friendly on-screen layout for entering and viewing data.                              | डेटा दर्ज करने व देखने हेतु सुविधाजनक स्क्रीन-लेआउट।                       |
| Report (Access)          | A formatted, printable summary of data from tables/queries.                                  | तालिकाओं/क्वेरी के डेटा का फॉर्मेटेड, प्रिंट-योग्य सारांश।                  |
