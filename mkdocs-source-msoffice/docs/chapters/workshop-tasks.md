# Chapter 8: Advanced Workshop — 60 Hands-On Practice Tasks {: #chapter-8 }

**अध्याय 8: उन्नत कार्यशाला — 60 व्यावहारिक अभ्यास कार्य**

This chapter is a complete, self-contained **task guide** for the Advanced MS Office Workshop &mdash; 60 hands-on
production tasks spread across 12 sections (5 tasks each), covering every unit of the VOI001 syllabus: MS Word,
MS Excel, MS PowerPoint, Internet &amp; Email, and MS Access. Each task is designed to take a focused student
roughly **10&ndash;15 minutes** of real typing, formatting, decorating or designing work &mdash; not a multiple-choice
quiz question, but an actual small deliverable you build yourself in the real application.

For every task you'll find: a short goal describing exactly what to produce, a picture of what the finished
output should look like, and a numbered list of procedure hints to get you there. Nothing here replaces your
own judgement &mdash; the hints tell you *which* commands to reach for, not the exact clicks, so there is room to
explore the ribbon and find your own way to the same result.

Use the companion **[Advanced MS Office Workshop Booklet](../../../workshop-booklet.html){target=_blank}**
to record your work, paste screenshots of each completed task, and answer the quiz and viva questions for each
section.

!!! info "Note on translation"
    Chapters 0–7 of this guide are presented bilingually (English and Hindi). Given the very large volume of
    original task content in this chapter (60 tasks across 12 sections), it is provided in English only at this
    time; a Hindi translation may be added in a future revision.

### Task 1.1 — Format a College Notice {: #task-1-1 }

**Goal (~10–15 min):** Type and format a one-page college notice announcing a workshop, with a centred bold title, a justified body paragraph, and a right-aligned date/signature block.

<img src="../../assets/workshop-outputs/1-1.png" alt="Expected output for Task 1.1" style="max-width:100%;border:1px solid #d7d7d7;border-radius:8px;margin:10px 0;">
<div style="font-size:11px;color:#666;margin-top:-4px;margin-bottom:14px;">&#9654; Expected output — Task 1.1 (MS Word)</div>

**Procedure / hints:**

1. Open a new blank Word document and set the page margins to Normal (2.54 cm all sides).
2. Type the title 'NOTICE — Workshop on Digital Literacy' and centre-align it; set font to 16 pt, Bold.
3. Below the title, type a 3–4 sentence announcement paragraph and justify it (Ctrl+J).
4. On a new line, right-align 'Date: __________' and 'Signature: __________' (Ctrl+R).
5. Save the file as Notice_YourRollNo.docx in your workshop folder.

**App, tabs &amp; features used:** Word — Home tab (Font group, Paragraph group, Alignment buttons); File > Save As

### Task 1.3 — Create a Multi-Level Numbered List {: #task-1-3 }

**Goal (~10–15 min):** Build a two-level numbered agenda for a college fest, with 4 main items and 2–3 sub-items under two of them.

**Procedure / hints:**

1. Type the title 'Annual Fest 2026 — Agenda'.
2. Start a numbered list (Home > Numbering) and type 4 main agenda items.
3. Place the cursor at the end of item 2, press Enter, then press Tab to demote to a sub-level; type 2 sub-items.
4. Repeat the demotion for item 3 with 2 sub-items of its own.
5. Adjust the multilevel list style if needed via Home > Multilevel List gallery.

**App, tabs &amp; features used:** Word — Home tab (Numbering, Multilevel List, Increase/Decrease Indent)

### Task 1.4 — Insert and Position an Image with Caption {: #task-1-4 }

**Goal (~10–15 min):** Insert a picture into a short report paragraph, wrap text around it, resize it proportionally, and add a numbered figure caption below it.

<img src="../../assets/workshop-outputs/1-4.png" alt="Expected output for Task 1.4" style="max-width:100%;border:1px solid #d7d7d7;border-radius:8px;margin:10px 0;">
